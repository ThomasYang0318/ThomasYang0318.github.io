Computer Vision · Image Classification

Sign Language Recognition

MATLABCNNSelf-AttentionASL

A 36-class image-classification prototype for recognizing static ASL fingerspelling gestures across the letters A-Z and digits 0-9.

Motivation

People who are unfamiliar with fingerspelling can find even basic communication difficult. This project explores whether image recognition can provide an accessible starting point for learning and recognizing individual hand gestures.

The prototype focuses on immediate visual feedback for a single gesture. It is intended as a learning and classification experiment, not as a complete translator for continuous sign language.

Dataset & scope

The project uses a public ASL image dataset obtained through Hugging Face and stored locally as asl_dataset. MATLAB reads the folder structure with imageDatastore, using each folder name as the class label.

Classes

36 static gestures: letters A-Z and digits 0-9.

Input

Each image is resized to 400 × 400 pixels before classification.

Task

Supervised single-image classification.

Current evidence

Validation accuracy is documented; a separate held-out test result is not yet available.

Model pipeline

The workflow adapts a basic MATLAB CNN classification example to a larger RGB input and a 36-class output. Convolution, batch normalization, ReLU, and pooling extract visual features before the classifier predicts a letter or number.

The classification pipeline resizes each ASL image, extracts CNN features, applies spatial attention, and predicts the gesture class.

Preprocessing

Load folder labels and resize RGB images to 400 × 400.

Feature extraction

Use convolution, normalization, activation, and pooling to learn visual hand features.

Classification

Map the learned representation to one of 36 gesture classes.

Training iterations

The initial four-epoch run recorded 2.86% validation accuracy, and the first augmentation experiment remained at 2.86%. A later 20-epoch run reached 93.14%, with an overfitting concern noted in the presentation. Reducing training to 10 epochs produced the highest documented validation result of 94.00% across 180 iterations. A further experiment compared learning rates of 0.001 and 0.0001.

These percentages are validation results documented in the linked presentation; they do not establish accuracy on an independent test set or in live use.

Stochastic gradient descent with momentum (sgdm).

Dropout and data augmentation were explored to reduce overfitting.

Learning rate

Experiments compared 0.001 with a lower 0.0001 setting.

Spatial self-attention

The SA model variants include a custom single-head spatial self-attention layer. It projects the CNN feature map into Query, Key, and Value representations, compares spatial positions, and reweights the features before classification.

This is a lightweight custom attention experiment rather than a complete Transformer block. Attention must be applied after spatial downsampling because its memory requirement grows quadratically with the number of feature-map positions.

Current demonstrator

The current MATLAB script loads the saved SA_net2.mat model and the local ASL image datastore. The user enters an image index, the selected image is resized to 400 × 400, and the model displays its predicted class above the image.

Input method

Select one existing dataset image by its numeric index.

Inference

Run MATLAB classify with the saved network.

Output

Display the selected image and its predicted letter or digit.

Limitations & next steps

The current system recognizes one static image at a time. It does not yet process a live camera feed, combine predictions into words, or translate continuous sign-language sentences and grammar. Dynamic gestures, including letters represented through motion, also require temporal information rather than a single frame.

Evaluation

Create an independent test split, confusion matrix, and per-class precision and recall.

Live input

Add webcam inference, confidence thresholds, and prediction smoothing.

Temporal gestures

Model motion across frames for dynamic signs and continuous input.
