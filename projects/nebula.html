Nebula Market

Flutterweb3dartSmart ContractNFT

A blockchain-based marketplace exploring how software licenses can be issued, verified, tracked, and transferred through smart contracts and NFT-backed ownership.

Overview

Developers can list software versions and issue corresponding licenses through smart contracts. When a user purchases a license, the contract mints an NFT tokenId to the user’s wallet. The application can then call a verification function before software launch to confirm that the user owns a valid license.

Watch demo ↗Presentation ↗

License flow

The project also supports resale between users. A license can be transferred through the contract, creating a software-licensing flow that is verifiable, traceable, and transferable.
