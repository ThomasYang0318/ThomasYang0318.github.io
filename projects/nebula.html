Nebula Market

FlutterDartweb3dartHardhatNFT

A blockchain-based marketplace exploring how software licenses can be issued, verified, tracked, and transferred through smart contracts and NFT-backed ownership.

Motivation

Nebula Market explores the difficulties independent software developers face when distributing their work: listing fees and review procedures, limited visibility into license ownership, and few ways for users to resell an existing license.

The prototype represents each software license as an NFT held in a user’s wallet. Smart contracts manage issuance, ownership checks, and transfers, while a Flutter application presents the marketplace and developer tools.

Application workflow

The interface separates publishing tools from purchasing and ownership records. Its navigation includes Marketplace, Free Market, My Purchases, My Creations, and Add App.

Register an app

Enter the application name and description to create an App ID. This identifies the software when publishing later versions.

Publish a version

Use the App ID to register a version and set its price in Wei. My Creations lists the developer’s uploaded applications.

Browse markets

The presentation distinguishes an official Marketplace with reviewed listings from a Free Market for more flexible listings and secondary license trading.

View purchases

My Purchases displays owned licenses with their License ID, software ID, and version, as shown in the supplied screenshot.

License lifecycle

A buyer chooses a software version in Flutter. The client uses web3dart to call buyLicense, and the contract issues an NFT license with a unique tokenId to the buyer’s wallet.

Software can call verify before enabling its functionality to check whether the user holds the required license. For resale, transferLicense changes the license owner through the contract.

This connects purchase, ownership verification, and transfer in one licensing workflow. Enforcement still depends on the software integrating the verification step.

Architecture & testing

The Flutter and Dart client provides the interface, and web3dart connects it to the smart contracts. The contracts manage license issuance, verification, and transfers.

Development and testing used a local Hardhat blockchain with deployed contracts. The presentation includes separate demonstrations of the application and a license purchase test. The documented result is a course prototype tested locally.

My contribution

The other team members handled backend design and programming, and system testing.
